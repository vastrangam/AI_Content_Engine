🕳️

How it works

One data core. One action cascades everywhere.

Every module reads and writes the same five entities. That is the physical reason a single goods receipt can touch stock, books, quality and sourcing at the same instant.

Goods receipt→ Stock +96→ Payable + ITC→ Debit note→ Scorecard
UNIFIED DATA CORE
Item / SKUPartyStockLedgerOrder
→ Inventory · stock in
→ Finance · payable & ITC
→ Quality · debit note
→ Sourcing · risk updated
← Planning · requirements
← Marketplace · order pull

Accepted — not ordered — is what counts

You order 100 metres. 100 arrive. Quality accepts 96. Most systems increase stock by 100 and claim tax credit on 100. Medhava increases stock by 96, claims input tax credit on 96, raises a debit note for the 4 rejected, and lowers that mill's accept rate — automatically.

Nothing derived is ever stored

Outstanding, risk, performance, aging, profit-per-design — all recomputed on read. They cannot drift out of step with the documents underneath them.

Questions

Frequently asked

What is Medhava?

Medhava is a unified ERP made of 14 modules and 48 apps that all read and write one shared data core — Item/SKU, Party, Stock, Ledger and Order. Because the data is shared, a single action such as a goods receipt updates stock, the ledger, quality records and the vendor scorecard at the same time.

How is Medhava different from Zoho or Odoo?

Zoho and Odoo are suites of separate applications that integrate with one another. Medhava is a single application with 14 modules over one data core and one event bus, so there is no synchronisation step between modules and no duplicate master data to reconcile.

Does Medhava support Indian GST?

Yes. Medhava posts double-entry vouchers with CGST, SGST and IGST, tracks TDS and TCS, computes input tax credit on accepted goods only, and produces GSTR-1 and GSTR-3B summaries. Existing BUSY data can be migrated in and exported back out.

Which marketplaces does Medhava connect to?

Amazon, Flipkart, Myntra, Meesho, Ajio, Nykaa and JioMart for orders and settlements, plus Shopify and WooCommerce for direct-to-consumer storefronts. Connections use revocable scoped API keys held in an encrypted vault — never account passwords.

Can Medhava be used outside textiles?

Yes. Every app ships in two configurations: a unified-ERP build with neutral master data suitable for any industry, and an industry-specific build. The engine, formulas and self-tests are identical in both; only the master data changes.

Is my data safe?

Data is isolated per company using PostgreSQL row-level security. Integrations use revocable scoped API keys in an AES-256-GCM encrypted vault. Every posting is written to an immutable audit trail with actor, timestamp and before/after values.

Can I use it without internet?

Yes. Each app is also delivered as a single HTML file that runs by double-clicking, works fully offline, stores data in the browser and exports a JSON backup. The hosted edition runs the identical engine against the shared backend.

How long does implementation take?

Starter runs the same day. A typical Growth rollout — catalogue, opening stock, opening balances and two marketplace channels — takes two to three weeks. Manufacturing and karigar payroll usually add another two weeks of parallel running.

Questions

Frequently asked

What is Medhava?

Medhava is a unified ERP made of 14 modules and 48 apps that all read and write one shared data core — Item/SKU, Party, Stock, Ledger and Order. Because the data is shared, a single action such as a goods receipt updates stock, the ledger, quality records and the vendor scorecard at the same time.

How is Medhava different from Zoho or Odoo?

Zoho and Odoo are suites of separate applications that integrate with one another. Medhava is a single application with 14 modules over one data core and one event bus, so there is no synchronisation step between modules and no duplicate master data to reconcile.

Does Medhava support Indian GST?

Yes. Medhava posts double-entry vouchers with CGST, SGST and IGST, tracks TDS and TCS, computes input tax credit on accepted goods only, and produces GSTR-1 and GSTR-3B summaries. Existing BUSY data can be migrated in and exported back out.

Which marketplaces does Medhava connect to?

Amazon, Flipkart, Myntra, Meesho, Ajio, Nykaa and JioMart for orders and settlements, plus Shopify and WooCommerce for direct-to-consumer storefronts. Connections use revocable scoped API keys held in an encrypted vault — never account passwords.

Can Medhava be used outside textiles?

Yes. Every app ships in two configurations: a unified-ERP build with neutral master data suitable for any industry, and an industry-specific build. The engine, formulas and self-tests are identical in both; only the master data changes.

Is my data safe?

Data is isolated per company using PostgreSQL row-level security. Integrations use revocable scoped API keys in an AES-256-GCM encrypted vault. Every posting is written to an immutable audit trail with actor, timestamp and before/after values.

Can I use it without internet?

Yes. Each app is also delivered as a single HTML file that runs by double-clicking, works fully offline, stores data in the browser and exports a JSON backup. The hosted edition runs the identical engine against the shared backend.

How long does implementation take?

Starter runs the same day. A typical Growth rollout — catalogue, opening stock, opening balances and two marketplace channels — takes two to three weeks. Manufacturing and karigar payroll usually add another two weeks of parallel running.
