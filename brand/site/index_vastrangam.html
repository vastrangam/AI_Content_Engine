What Vastrangam BOS is

One application. Not eleven that talk to each other.

Every other suite sells you separate products and a sync job between them. Vastrangam BOS is a single application over one set of records — so there is nothing to synchronise, and nothing to reconcile.

1

Enter it once

A goods receipt, a counter sale, a marketplace order — recorded in one place. Stock, the ledger, the quality record and the supplier scorecard all update in the same instant, because they are reading the same record.

2

Numbers that cannot disagree

One stock figure per SKU. One ledger. One order record. Not a copy per channel that somebody reconciles on Saturday. When the website says four are left, four are left.

3

Built for how India actually runs

GST with input credit on accepted goods, TDS and TCS, seven marketplaces, piece-rate karigar wages — and apps that keep working when the internet does not.

The statement is what an auditor or a partner asks for before they will connect to this system.

How it is kept straight

The rules, the checks, and what we will not claim.

Software that runs a business earns trust by being checkable, not by being described well. These are the standards this build is held to — written down, because a standard nobody wrote down is a standard nobody can be held to.

The rules that hold everywhere
Integrity
  • No app depends on any single outside company — every capability has interchangeable providers and a by-hand option
  • A provider named as the source of a figure is a bug; the ledger originates numbers
  • The books are this system's own — no other accounting package is ever required
  • Money is integer paise, never a floating-point number
  • Salaries, prices, tax rates and commissions are effective-dated — March payroll uses March's salary
What it refuses to do
Safety
  • Never asks for a marketplace, bank or account password — scoped, revocable keys only
  • Nothing is deleted, only deactivated — history must still resolve
  • The audit trail has no off switch: 8 years, before-and-after values
  • Gates, not warnings — a COD order cannot be packed below its advance, a bill for more than was accepted cannot be paid
  • It is not trained, it is built — no model learns from your data
How it is verified
Evidence
  • The arithmetic runs with no screen involved, against seeded data
  • Every screen and every control is clicked in a real browser — any console error fails the build
  • Not "did the button click" but "did the thing happen"
  • Against the owner's own figures: the karigar run must return 25,307 sets, 59,110 pieces, ₹26,90,062
  • The shipped archive is re-tested after extraction, not just the working copy
What we will not claim
Honesty
  • Nothing is called finished that is not — every app above is marked working today or to build
  • Counts are counted from the source at build time, never typed by hand
  • If a test fails, the failure is shown with its output
  • The 16 working apps still run on their own storage — rewiring them onto the shared core is the first job of Module 01
  • 82 apps are designed and specified, not yet written

The approach

You order 100. 100 arrive. Quality accepts 96. Most systems raise stock by 100 and claim tax credit on 100. Vastrangam BOS raises stock by 96, claims credit on 96, raises a debit note for the 4, and lowers that supplier's accept rate. Automatically.

02

The payout, to the order line

Not "the channel paid ₹49.1 lakh". Which order line was short, by how much, against which published commission rate — with the claim pack already assembled and the packing footage attached.

03

Nothing derived is stored

Outstanding, ageing, promise dates, payouts, on-time percentage and risk are recomputed every time you read them. A stored number goes stale the moment the document under it changes. These cannot.

Questions

Frequently asked

What is Vastrangam BOS?

Vastrangam BOS is a unified ERP made of 20 modules and 98 apps that all read and write one shared data core — Item/SKU, Party, Stock, Ledger and Order. Because the data is shared, a single action such as a goods receipt updates stock, the ledger, quality records and the vendor scorecard at the same time.

How is Vastrangam BOS different from Zoho or Odoo?

Zoho and Odoo are suites of separate applications that integrate with one another. Vastrangam BOS is a single application with 20 modules over one data core and one event bus, so there is no synchronisation step between modules and no duplicate master data to reconcile.

Does Vastrangam BOS support Indian GST?

Yes. Vastrangam BOS posts double-entry vouchers with CGST, SGST and IGST, tracks TDS and TCS, computes input tax credit on accepted goods only, and produces GSTR-1 and GSTR-3B summaries. Existing BUSY data can be migrated in and exported back out.

Which marketplaces does Vastrangam BOS connect to?

Amazon, Flipkart, Myntra, Meesho, Ajio, Nykaa and JioMart for orders and settlements, plus Shopify and WooCommerce for direct-to-consumer storefronts. Connections use revocable scoped API keys held in an encrypted vault — never account passwords.

Can Vastrangam BOS be used outside textiles?

Yes. Every app ships in two configurations: a unified-ERP build with neutral master data suitable for any industry, and an industry-specific build. The engine, formulas and self-tests are identical in both; only the master data changes.

Is my data safe?

Data is isolated per company using PostgreSQL row-level security. Integrations use revocable scoped API keys in an AES-256-GCM encrypted vault. Every posting is written to an immutable audit trail with actor, timestamp and before/after values.

Can I use it without internet?

Yes. Each app is also delivered as a single HTML file that runs by double-clicking, works fully offline, stores data in the browser and exports a JSON backup. The hosted edition runs the identical engine against the shared backend.

How long does implementation take?

Starter runs the same day. A typical Growth rollout — catalogue, opening stock, opening balances and two marketplace channels — takes two to three weeks. Manufacturing and karigar payroll usually add another two weeks of parallel running.
